# AI 명함 스튜디오 — 프론트엔드 (실제 웹사이트용)

이건 지금까지 Claude 아티팩트로 써오시던 것과 **똑같은 화면·기능**입니다. 다만 이번엔
Claude 안이 아니라, 진짜 인터넷 주소로 여는 독립된 웹사이트로 만든 버전입니다 —
파일 업로드(카메라·갤러리)가 Claude 아티팩트 안에서 안 열리는 문제가, 진짜
웹사이트에서도 그런지 확인하기 위한 목적이 가장 큽니다.

## 1. GitHub에 올리기

지난번 서버(`bizcard-studio-server`) 올리실 때와 완전히 같은 방법입니다.

이 폴더 안의 내용물 전체(`src` 폴더, `index.html`, `package.json`, `vite.config.js`,
`.gitignore`)를 GitHub에서 새 저장소를 만들어서 업로드하시면 됩니다. 저장소 이름은
예를 들어 `bizcard-studio-frontend`로 하시면 됩니다.

**주의**: 지난번처럼 "기존 파일을 업로드하여" 방식을 쓰실 때, `src` 폴더는 폴더
그대로 끌어다 놓으셔야 합니다(서버 때와 반대입니다 — 이번엔 `src/App.jsx`처럼
폴더 구조가 그대로 유지되어야 합니다). 웹 업로드 화면에서 폴더째 끌어다 놓으면
보통 구조가 그대로 유지됩니다.

## 2. Render에서 배포하기

1. Render 대시보드 → "New" → 이번엔 **"Static Site"** 선택(Web Service 아닙니다!)
2. 방금 만든 `bizcard-studio-frontend` 저장소 선택
3. 설정값:
   - **Name**: 아무 이름 (예: bizcard-studio-frontend)
   - **Branch**: main
   - **Build Command**: `npm install && npm run build`
   - **Publish Directory**: `dist`
4. 환경변수는 필요 없습니다(전부 코드 안에 이미 있는 공개 정보만 씁니다).
5. "Create Static Site" 클릭 → 몇 분 기다리면 배포됩니다.
6. 배포가 끝나면 `https://bizcard-studio-frontend.onrender.com` 같은 주소가 생깁니다.

## 3. 확인하기

1. 그 주소를 **핸드폰 브라우저**(Chrome이나 삼성 인터넷 등, Claude 앱이 아닌 일반
   브라우저)로 열어보세요.
2. 디자인 화면까지 들어가서 "사진 업로드" 버튼을 눌러보세요.
3. **여기서 카메라·갤러리가 열리면**: Claude 아티팩트 환경 자체의 제약이었다는 게
   확정됩니다. 이제부터는 이 실제 웹사이트 주소로 손님들에게 서비스하시면 되고,
   Claude 대화창은 개발용으로만 쓰시면 됩니다.
4. **여기서도 안 열리면**: 코드 쪽 문제가 맞다는 뜻이니, 그 화면 캡처해서 보여주세요 —
   이번엔 실제 배포 환경이라 브라우저 개발자도구(F12 → Console)로 진짜 에러 메시지도
   확인할 수 있어서 훨씬 빠르게 원인을 찾을 수 있습니다.

## 참고
- 이 사이트는 지금 백엔드 서버(`https://bizcard-studio-server.onrender.com`)를
  그대로 바라보고 있어서, 주문·회사 등록 등은 지금까지 확인하신 것과 동일하게
  실제로 저장됩니다.
- AI 캐시·문의 메시지 등 일부 기능은 이 사이트에서는 브라우저 저장소(localStorage)를
  씁니다 — 나중에 이것도 실제 서버로 옮기면 더 좋아집니다(지금은 급하지 않음).
